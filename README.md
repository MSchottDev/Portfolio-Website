# MSchottDev-Portfolio

Dieses Repository enthält meine **Portfolio-Website**, das aktuell dazu dient, **Frontend-Fähigkeiten in HTML, CSS und JavaScript** zu festigen. 

Die Seite zeigt:
- meine Person
- meinen Tech-Stack
- erste Projekte als Referenzen

Langfristig soll das Projekt zu einer **vollwertigen Portfolio-Seite** ausgebaut werden, mit
Deployment auf Azure.


Der aktuelle Stand legt den Fokus auf:
- sauberes, semantisches HTML
- modernes CSS (Flexbox/Grid)
- responsive Gestaltung
- strukturierte Inhaltsdarstellung

## Projektstruktur
```
MSchottDev-Portfolio/
├─ index.html         # Startseite
├─ CSS/
│  └─ style.css       # Hauptstylesheet
├─ IMAGES/            # Bilder für Portfolio/Projekte
└─ README.md          # Projektdokumentation
```
