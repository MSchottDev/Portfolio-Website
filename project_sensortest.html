Sensor-Testsystem

Entwicklung einer Python-Anwendung zur automatisierten Sensorerkennung, Metadatenauswertung sowie Durchführung von Distanz- und Amplitudentests.

Python PyQt5 Pytest Sensor API Serial Communication Testautomatisierung Subprocess GUI Development

Projektbeschreibung

Im Rahmen meiner IHK-Facharbeit habe ich ein Python-basiertes Testsystem zur Erkennung und Überprüfung von Sensoren entwickelt.

Ziel der Anwendung war es, mehrere Sensoren automatisch zu erkennen, deren technische Metadaten auszulesen und anschließend definierte Funktionstests durchführen zu können.

Die Anwendung verfügt über eine grafische Benutzeroberfläche, über die angeschlossene Sensoren verwaltet und einzelne oder mehrere Tests gestartet werden können.

Neben der manuellen Anzeige von Messwerten können automatisierte Tests für Distanz und Amplitude ausgeführt werden. Die Ergebnisse werden anschließend als Testreports gespeichert und innerhalb der Anwendung angezeigt.

Für die Weiterentwicklung und Demonstration des Projekts wurde zusätzlich eine Sensorsimulation integriert. Dadurch kann die Anwendung auch ohne angeschlossene Hardware ausgeführt und getestet werden.

Funktionen

Sensorerkennung

Die Anwendung durchsucht verfügbare Schnittstellen und erkennt angeschlossene Sensoren automatisch.

Sensormetadaten

Nach der Erkennung werden unter anderem Sensortyp, Seriennummer und verwendeter COM-Port ausgelesen und in der GUI dargestellt.

Live-Messwerte

Der aktuelle Distanzmesswert eines Sensors kann direkt über die grafische Oberfläche abgefragt und angezeigt werden.

Distanztest

Für jeden erkannten Sensor kann ein automatisierter Distanztest durchgeführt werden. Die Messwerte werden gegen definierte Grenzwerte geprüft.

Amplitudentest

Zusätzlich kann die Signalstärke bzw. Amplitude der Sensoren automatisiert überprüft werden.

Gesamtprüfung

Über die Funktion „TEST ALL“ können Distanz- und Amplitudentests nacheinander für die erkannten Sensoren ausgeführt werden.

Testreports

Die Testergebnisse werden über Pytest erzeugt, als Reports gespeichert und anschließend in der Anwendung dargestellt.

PASS / FAIL Status

Die Oberfläche visualisiert das Ergebnis jedes Tests unmittelbar als PASS oder FAIL.

Sensorsimulation

Eine integrierte Simulation stellt Sensoren, Messwerte und Metadaten bereit, sodass das Projekt auch ohne physische Hardware ausgeführt werden kann.

Projekt-Einblicke

Screenshots zeigen die grafische Benutzeroberfläche, die Sensorerkennung sowie die Durchführung und Auswertung der automatisierten Tests.

Die Anwendung ist in mehrere funktionale Bereiche aufgeteilt. Die PyQt5-Oberfläche übernimmt die Benutzerinteraktion und stellt erkannte Sensoren sowie Testergebnisse dar. Die Sensorverwaltung kapselt die Erkennung und Verwaltung der Sensorinstanzen. Über die Sensor- Schnittstelle werden Metadaten und Messwerte ausgelesen. Die eigentlichen Prüfungen werden über Pytest automatisiert ausgeführt. Die Testprozesse werden aus der Anwendung heraus gestartet und ihre Ergebnisse anschließend als Reports verarbeitet.

Sensorerkennung und Metadaten

Beim Start der Sensorerkennung werden die verfügbaren COM-Schnittstellen ermittelt und anschließend auf vorhandene Sensoren überprüft.

Erkannte Sensoren werden in einer zentralen SensorRegistry verwaltet. Dadurch können die Sensorinstanzen innerhalb der Anwendung gezielt angesprochen und für Messungen und Tests verwendet werden.

COM-Port Schnittstelle, über die der Sensor erkannt wurde
Sensor Type Ermittelter Sensortyp
Serial Number Eindeutige Seriennummer des Sensors
Distance Aktuell gemessener Distanzwert

Automatisierte Tests

Ein zentraler Bestandteil des Projekts ist die automatisierte Überprüfung der Sensoren. Die Tests werden mit Pytest umgesetzt und aus der grafischen Anwendung heraus gestartet.

Für den Distanztest wird der aktuelle Messwert eines Sensors ausgelesen und gegen einen definierten Wertebereich geprüft.

Zusätzlich wird die Amplitude des Sensors überprüft. Die Tests können entweder einzeln für einen Sensor oder für alle erkannten Sensoren ausgeführt werden.

Sensor → Messwert → Pytest → PASS / FAIL → Testreport

Testreports und Auswertung

Die Ergebnisse der automatisierten Prüfungen werden für jeden Sensor separat gespeichert.

Die Anwendung startet die Pytest-Testfälle über einen separaten Prozess und schreibt dessen Ausgabe in entsprechende Report-Dateien.

Über die grafische Oberfläche können die erzeugten Reports anschließend angezeigt werden. Zusätzlich wird das Testergebnis direkt am jeweiligen Sensor visualisiert.

Erfolgreicher Test

  • Pytest beendet sich erfolgreich
  • Teststatus: PASS
  • Ergebnis wird in der GUI angezeigt
  • Report bleibt zur Analyse erhalten
→

Fehlgeschlagener Test

  • Grenzwert wird nicht eingehalten
  • Teststatus: FAIL
  • Fehler wird im Report dokumentiert
  • Ergebnis kann anschließend analysiert werden

Sensorsimulation

Um das Projekt unabhängig von der ursprünglichen Sensorhardware ausführbar zu machen, wurde eine eigene Sensorsimulation integriert.

Die simulierten Sensoren stellen dieselben grundlegenden Schnittstellen bereit, die auch von der eigentlichen Anwendung verwendet werden. Dadurch kann die bestehende GUI- und Testlogik weiterverwendet werden.

Die Simulation erzeugt realistische Schwankungen bei Distanz- und Amplitudenmesswerten. Zusätzlich sind unterschiedliche Sensoren mit eigenen Seriennummern, Sensortypen und Messwerten definiert.

Ein Sensor ist bewusst so konfiguriert, dass er die definierten Grenzwerte nicht erfüllt. Dadurch lässt sich auch das Verhalten eines fehlgeschlagenen Tests demonstrieren.

Simulierter Sensor → SensorRegistry → GUI → Pytest

Grafische Benutzeroberfläche

Die Benutzeroberfläche wurde mit PyQt5 entwickelt und stellt die wichtigsten Funktionen des Testsystems zentral zur Verfügung.

Für bis zu sechs Sensoren werden jeweils Sensortyp, Seriennummer, COM-Port und aktueller Distanzwert angezeigt.

Über separate Schaltflächen können einzelne Sensoren getestet oder komplette Testläufe für alle erkannten Sensoren gestartet werden.

Ein integriertes Log- und Reportfenster ermöglicht zusätzlich die Anzeige der detaillierten Testergebnisse.
